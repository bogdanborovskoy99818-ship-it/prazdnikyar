# Праздник.яр — MVP-прототип

Интерактивный прототип пользовательской части агрегатора детских праздников в Ярославле.

## Запуск

Откройте `index.html` двойным щелчком. Для корректной PWA-установки и кэширования запустите локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Что работает

- каталог, поиск, категории, фильтры и сортировка;
- демонстрационный умный подбор по текстовому описанию;
- карточки услуг, отзывы, галерея, карта и выбор параметров;
- избранное и конструктор праздника с сохранением в браузере;
- расчёт бюджета и демонстрационное оформление заявки;
- адаптивная мобильная версия и базовая PWA-конфигурация;
- форма для организатора «Выставить свои услуги».

Все объявления, цены, рейтинги, адреса, отзывы и свободные даты — демонстрационные. Сервер, база данных, авторизация, настоящая нейросеть, сообщения, оплата и отправка заявок в этот статический MVP не входят.
